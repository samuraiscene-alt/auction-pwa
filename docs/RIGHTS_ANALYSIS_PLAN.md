# 권리분석·낙찰자 인수금액 계산 — 확정 필수 개발 계획
확정일: 2026-11-11 · 상태: 요구사항 확정, 구현 전 · 기준 앱 v0.7.38

## 목표
경매 물건별 원본 서류를 기반으로 말소기준권리·선순위권리·임차인·배당 및 인수 가능성 검토를 돕고, 낙찰가 외 추가 부담 시나리오를 제시한다. 자료 미확인 상태에서 '안전' 또는 '인수금 0원' 단정은 금지한다. 한국 법률 판단의 자동 확정이나 변호사/법무사 검토 대체를 주장하지 않는다.

## 핵심 데이터 모델
- 물건 식별: courtCode + caseNo + itemNo. 법원 수집물건과 직접 등록물건 출처 구분. 수집 당시 자료와 최신 확인 상태 별도.
- 서류: 문서 종류(매각물건명세서/현황조사서/감정평가서/등기사항증명서/임대차 관련/기타), 원문 파일 또는 링크, 발급·열람·등록 날짜, 사용자/공식 출처, 검증 여부, 진위 미확인 여부.
- 등기 권리 항목: 권리 유형, 권리자(보안상 최소화), 접수/설정 날짜 및 순위번호, 채권최고액 또는 금액, 범위/특약, 확인 서류/페이지, 불확실 사유.
- 임차인 항목: 점유, 전입일, 확정일자, 보증금, 배당요구 여부·기일, 배당예상/확인 금액, 대항력 관련 미확인 사항, 출처 문서/페이지. 비식별 표기 우선.
- 특수조건: 유치권 주장, 법정지상권, 대지권, 가등기, 처분금지가처분, 별도등기, 선순위 임차인, 제시외 건물, 토지/건물 별도 권리 등. 자동 판정이 아닌 검토 항목.
- 금액: 낙찰가, 인수 가능 보증금, 배당 가능액, 취득세, 법무/등기 비용, 명도비, 기타 부대비용; 각 금액은 source, known/assumed/unknown, 계산근거를 가진다.

## 단계별 제공 기능
1. 사용자 수동 자료·PDF 가져오기, 사건번호·물건번호 대조, 서류 종류/발급일/출처 등록. 법원 공식 원본 자동 가져오기는 제공 가능성과 권한을 먼저 검증한다.
2. 권리 목록/임차인 목록 구조화 입력과 수정·검증. 사건별, 물건번호별로 분리 저장. 기존 공부노트/관심자료의 저장키 및 백업 포맷을 파괴하지 않는다.
3. 말소기준권리 후보 및 인수 가능성 점검 체크리스트. 권리순위/점유/대항요건/배당요구를 하나의 규칙으로 단정하지 않음. 원본 서류가 모순되면 '확인 필요' 상태.
4. 인수액 시나리오: 낙찰자가 부담할 수 있는 잔여 보증금 등은 법적 인수요건과 배당충족 검증 없이 확정 불가. 가정된 배당액으로 계산 시 반드시 '가정' 표시.
5. 총부담 시나리오 = 낙찰가 + 별도 인수 가정액 + 취득·등기·명도·기타 비용. 미상 항목이 하나라도 중요한 경우 확정 총액 대신 **부분 합계 + 산정 불가/추가 위험** 표시. 낙찰 예정가와 보증금 비율은 법원 공고 확인.
6. 자료 업데이트/서류 교체 시 분석결과를 재검증 필요로 전환. 과거 검증을 최신 결과처럼 사용하지 않는다.

## 판정 및 UX
- 상태: 확인된 사실 / 사용자 가정 / 확인 필요 / 자료 충돌. 결과별 출처 문서·페이지·확인일·계산식 표시.
- 화면은 기존 상세 '권리' 탭 안에서 단계적으로 확장. '서류' 탭과 연결. 현재 권리분석 안내/공부방/PDF 메모/하단 네비게이션/이미지 아이콘 변경 금지.
- 총인수금액 산정 불가일 때 0원 또는 위험 없음 표시 금지. 금액 계산은 원 단위 정수, 금액 상한/음수/중복 검증.
- 저장 성공 시 실제 저장 확인 후 앱 표준 중앙 원형 V 체크 표시.
- 사용자 로컬 데이터 기기 저장 우선, 향후 백업·복원 시 마이그레이션 및 구형 백업 호환성 테스트 필수.
