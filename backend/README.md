# 법원 조회 연결 서버 (개발용)

현재 파일: `backend/court-worker.js`

## 목적
법원경매정보 내부 조회 API를 아이폰 PWA가 직접 호출할 수 없는 경우, Cloudflare Worker에서 서버 측에 한 번 요청하고 검증된 최소한의 사건 식별 정보만 응답합니다. GitHub Pages 앱은 계속 유지합니다.

## 현재 상태
- **소스만 준비됨. Worker 배포 및 앱 연결은 아직 진행하지 않음.**
- 사건번호와 법원 코드 일치를 검증하고, 이름/개인정보/원문 응답 전체를 반환하지 않습니다.
- 감정가·최저가·매각기일은 응답 필드별 값·단위·사건 일치를 검증하기 전에는 자동으로 표시하거나 저장하지 않습니다.
- 법원의 비공식 내부 API가 변경되거나 차단될 수 있습니다. 서비스 이용조건 및 호출 빈도를 확인해야 합니다.
- 사용 예 (배포 후): `GET https://<your-worker>.workers.dev/case?courtCode=B000210&caseNo=2023%ED%83%80%EA%B2%BD4869`
- Cloudflare Worker 배포 계정과 발급받은 URL이 있어야 앱과 연결할 수 있습니다. **GitHub Actions의 성공만으로 Worker가 배포되는 것은 아닙니다.**
